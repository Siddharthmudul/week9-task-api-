Authentication

POST /api/auth/register

Register a user. On success, the API returns a user profile and access/refresh tokens.

Request body

{
  "username": "john_doe",
  "email": "john@example.com",
  "password": "SecurePass123"
}

201 Created

{
  "status": "success",
  "data": {
    "message": "User registered successfully",
    "user": {
      "id": 1,
      "username": "john_doe",
      "email": "john@example.com",
      "created_at": "2024-01-25T10:30:00Z"
    },
    "access_token": "<jwt>",
    "refresh_token": "<jwt>"
  }
}

Send the access token with protected requests using Authorization: Bearer <access_token>.

Tasks

GET /api/tasks
Requires a Bearer access token

Lists tasks owned by or assigned to the authenticated user.

Query parameters

ParameterDefaultDescription
page1Page number
per_page10Items per page (maximum 100)
status—pending, in_progress, or completed
priority—low, medium, or high
sort_bycreated_atcreated_at, due_date, or priority
sort_orderdescasc or desc

200 OK
